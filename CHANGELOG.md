# История изменений

Формат по мотивам [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [семантическому версионированию](https://semver.org/lang/ru/).

## [Не выпущено]

### Исправлено

- пакет не вставал на систему с другой патч-версией Qt: QML собирался с
  опережающей компиляцией, а та тянет приватный ABI (`Qt_6.11.1_PRIVATE_API`);
  теперь QML переводится только в байткод;
- установка RPM на Fedora падала с «nothing provides
  /usr/lib64/qt6/qml/...»: dnf5 не разрешает зависимости от каталогов —
  для Fedora модули QML требуются по именам пакетов.

## [0.1.0]

Первый рабочий выпуск.

### Добавлено

- вход через Яндекс ID (OAuth + PKCE);
- подключение Диска как папки: чтение диапазонами, запись, переименование,
  удаление в корзину;
- окно на Kirigami: обзор Диска, поиск, корзина, настройки, «О программе»;
- миниатюры изображений от Яндекса — сами файлы при этом не скачиваются;
- публичные ссылки, в том числе с паролем и сроком действия;
- копирование на стороне Яндекса, загрузка по внешней ссылке;
- перетаскивание файлов и папок из системы;
- закрепление файлов офлайн, ограничение кэша, его очистка;
- слежение за изменениями на других устройствах;
- очередь повторной выгрузки и защита от перезаписи чужих правок;
- значок в системном лотке, уведомления, автозапуск;
- эмблемы состояния и меню Orbita в Dolphin;
- пакеты RPM и DEB, `PKGBUILD` для AUR.
